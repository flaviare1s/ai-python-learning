## ⚙️ Instalação e Configuração

Para rodar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/flaviare1s/ai-python-learning.git
    cd ai-python-learning
    ```

2.  **Crie um ambiente virtual (opcional, mas recomendado):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux/macOS
    venv\Scripts\activate     # Windows
    ```

3.  **Instale as dependências:**
    Como este projeto está em constante evolução, certifique-se de ter as bibliotecas base instaladas:
    ```bash
    pip install notebook pandas scikit-learn matplotlib
    ```
